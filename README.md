# Harshad Number Analyzer in C++

A modular C++ program that evaluates Harshad numbers—integers divisible by the sum of their digits. The project reinforces decomposition, reusable functions, numeric processing, and verification.

## Highlights

- Computes the digit sum of an integer
- Determines whether values satisfy the Harshad-number property
- Separates declarations, implementation, and program flow
- Uses repeatable test cases to verify expected results

## Key Files

| File | Purpose |
| --- | --- |
| `LAB_Harshad_Numbers_V3.cpp` | Program entry point and test flow |
| `Module.h` | Function declarations |
| `Module.cpp` | Harshad-number logic |

## Skills Demonstrated

C++, modular programming, integer arithmetic, algorithm design, debugging, and result verification.
